# 故事大纲（节点化主线版）

> 用法：把下面的骨架替换成你的故事大纲。**每个锚点是一个必达里程碑**（不是参考标尺），
> 写手可以自由设计到达路径，但不能绕过。引擎按章号自动注入「当前幕」的锚点段落（防剧透+省 token）。

## 锚点定义格式（◆ 锚N 标题（第X~Y章）：一句话）

```markdown
◆ 锚1 觉醒（第1~5章）：主角第一次发现异常
- 必达：本章必须落地的目标（硬，至少1个事件/行动/推进）
- 回收伏笔：V-01, 会算的陌生人     ← 【可选】该锚区间要回收的伏笔（V-01=账本表格ID，或直接写伏笔名称）
- 必写：场景/元素/氛围要求
- 余白：可以省略/跳过的内容
```

> 字段说明：
> - **回收伏笔**：伏笔账本里待回收的条目（用表格 ID `V-01` 或条目名称都行，多个用逗号分隔）。
>   引擎写章时会把「当前章所属锚」的回收伏笔注入为**应收网**（必须回收），防止伏笔悬空/被支线带跑。
> - 同一伏笔可被多个锚标注（引擎自动合并去重）。
> - 不写回收伏笔 = 该锚不强制回收，引擎只注入主线未回收前3条（可铺垫禁展开）。

## 建议骨架

【主题】一句话
【主角弧光】起点 → 终点
【核心冲突】一句话
【结局基调】不是大团圆，是"生活继续"
