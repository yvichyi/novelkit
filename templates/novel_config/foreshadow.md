# 伏笔账本（埋设→回收 全记录）

> 引擎会自动登记评审输出的伏笔；你也可以手工编辑本文件。
> 格式（两种都兼容）：

## 主表（表格格式，主线伏笔登记在这里）

| ID | 内容 | 埋设章 | 计划回收 | 状态 | 关联 |
|:---|:---|:---|:---|:---|:---|
| V-01 | 伏笔一句话描述 | 第1章 | 中期 | 已埋 | 主线/支线 |
| （新增） | | | | | |

## 第N章 伏笔登记（评审自动登记区，主线）

- 伏笔名称｜级别A/B/C｜主线/支线｜预计X回收
- 回收｜伏笔名称

## 支线池（暂不回收，回收时转主表）

- 支线伏笔名称｜级别B｜支线｜预计X回收

## 回收记录（已回收的伏笔移到这里）

| ID | 内容 | 埋设章 | 回收章 | 回收方式 |
|:---|:---|:---|:---|:---|

## 已舍弃（氛围描写/一次性事件，不再回收）

> 当章就完成叙事功能的描写**不是伏笔**，列此备忘避免误当伏笔。

---

### 分级规则（登记前自评）
- **A 核心**：支撑主线 / 能引爆剧情 / 读者必须记住 → 登记，**必须回收**
- **B 观察**：有价值、可能回收（辅助线索、支线钩子、人物小悬念）→ 可登记，择机回收
- **C 噪音**：过程性细节、氛围描写、一次性事件 → **不登记**，随写随用
- **主线/支线标注**：与主线无关的一律标「支线」→ 自动进支线池冷冻，不干扰主线注入
- 回收时机：在大纲锚点定义里写 `- 回收伏笔：V-01, 名称`，引擎到该锚区间会自动催收
